# Modelos 3D (v1 provisional, aprobados en estilo)
Low-poly hechos a mano con código (trimesh, script `construir.py` en el paquete de supervisión). `casa.gltf` + `01.gltf`…`08.gltf` (glTF con buffer embebido, equivalente a GLB); cada parte es un mesh `part_*` igual al campo `mesh` de data/contenido.json. Peso total ≈170 KB. Colores por vértice en la paleta institucional (ver STYLE.md del paquete).
