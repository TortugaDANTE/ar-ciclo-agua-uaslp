# Target MindAR del cartel
Falta `cartel.mind` (PROVISIONAL: la app no detecta nada hasta subirlo).
1. Exportar el cartel tabloide final a PNG/JPG (~1000–2000 px de ancho, mismo arte que se imprime).
2. Abrir el compilador gratuito oficial: https://hiukim.github.io/mind-ar-js-doc/tools/compile
3. Subir la imagen (un solo target, índice 0) → Start → Download `targets.mind`.
4. Renombrar a `cartel.mind` y colocarlo en esta carpeta.
Consejos: alto contraste, mucho detalle, sin grandes zonas planas ni patrones repetidos; impresión mate.
